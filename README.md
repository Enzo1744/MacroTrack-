# MacroTrack V1.0
PWA statique, sans dépendance ni compte. Pour tester sur ordinateur : `python -m http.server 8000`, puis http://localhost:8000. Pour installer sur iPhone, héberger tous les fichiers ensemble sur un hébergeur statique HTTPS (par exemple GitHub Pages), ouvrir l'adresse dans Safari, Partager > Sur l'écran d'accueil. Attendre la première ouverture en ligne avant de tester hors connexion. Les données restent locales au navigateur/application et peuvent être perdues si le stockage est effacé. Export JSON dans Profil. Les valeurs génériques et coefficients sont indicatifs; créer les produits exacts à partir des emballages. Les objectifs de glucides et lipides sont des valeurs initiales modifiables, non une prescription. Pas de scanner, API alimentaire, synchronisation cloud ni suivi du poids dans cette version. Pour les futures versions, changer le nom du cache dans sw.js.
